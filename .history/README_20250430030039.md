# Computer Vision Projects

This repository contains four mini-projects that demonstrate various applications of computer vision using Python and OpenCV.

## 📁 Included Projects

### 1. 🎨 Colorization of the Russian Empire
Automatic colorization of historical black-and-white photos from the Russian Empire using pretrained neural networks.

### 2. 🗻 Panorama Creation
Merging multiple overlapping images to generate a single panoramic view using feature detection and matching techniques.

### 3. 🚧 Traffic Sign Detection
Detection and classification of road signs from input images using preprocessing and supervised learning models.

### 4. 🙂 Face Detection
Real-time detection of human faces using Haar Cascade classifiers with OpenCV.

## 🛠️ Technologies Used
- Python
- OpenCV
- NumPy
- Scikit-learn (for some projects)
- Matplotlib
